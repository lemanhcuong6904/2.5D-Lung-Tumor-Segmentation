# TransUNet 2D and 2.5D Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a reproducible, config-only supervised TransUNet pipeline for binary 2D and 2.5D lung-tumor segmentation.

**Architecture:** One slice-indexed dataset produces a configurable odd number of axial context slices as input channels and the centre-slice label as target. A parameterized TransUNet predicts one centre-slice logit; shared metrics rebuild complete volumes for case-mean evaluation, while train and inference scripts orchestrate experiment artifacts.

**Tech Stack:** Python, PyTorch, Albumentations, NumPy, SciPy, SimpleITK, Pillow, Weights & Biases, pytest.

**Spec:** `docs/superpowers/specs/2026-09-07-transunet-25d-design.md`

## Global Constraints

- Do not use `argparse`, environment variables, or command-line arguments in the new training or inference pipeline; every runtime setting is a top-level `CFG` dictionary entry.
- Source PNGs are `data/processed/<case_id>/images/<slice>.png` and matching labels are under `labels/`; image values are normalized from uint8 to `[0, 1]`, labels are binary `float32` values in `{0.0, 1.0}`.
- `NUM_SLICES` is a positive odd number: `1` is 2D and `3` or `5` is 2.5D. Boundary context indices are clamped.
- Spatial Albumentations must transform every context channel and the centre mask identically; validation and inference must be deterministic and unaugmented.
- The model returns one unnormalized binary logit per pixel. Loss is `BCEWithLogitsLoss + sigmoid Dice loss`.
- AMP runs only when `CFG["AMP"]` is true and device type is CUDA. W&B failure or opt-out must not stop an experiment.
- Learning rate uses 10% linear warmup then cosine decay. Training stops after five epochs without a strictly lower `val_loss`.
- W&B epoch logs include `train_loss`, `train_dice_2D`, `train_dice_3D`, `val_loss`, `val_dice_2D`, and `val_dice_3D`.
- 2D metrics are slice means; 3D metrics are case means. 3D HD95 and ASSD use reference NIfTI spacing and become `NaN` when either volume is foreground-empty.
- The workspace is not a Git repository. Do not run Git commit commands; record verification results in the implementation handoff instead.

```python
class LungTumorSliceDataset(Dataset):
    def __init__(self, processed_root, case_ids, num_slices, transform=None):
        if num_slices < 1 or num_slices % 2 == 0:
            raise ValueError("num_slices must be a positive odd integer")
        self.items = _build_slice_items(Path(processed_root), case_ids)
        self.num_slices, self.transform = num_slices, transform

    def __getitem__(self, index):
        item = self.items[index]
        channels = _load_context(item, self.num_slices)
        mask = _load_binary_mask(item.label_path)
        if self.transform is not None:
            result = self.transform(image=np.moveaxis(channels, 0, -1), mask=mask)
            channels, mask = np.moveaxis(result["image"], -1, 0), result["mask"]
        return {"image": torch.from_numpy(channels.copy()), "mask": torch.from_numpy(mask[None].astype(np.float32)), "case_id": item.case_id, "slice_index": item.slice_index}
```

- [ ] **Step 3: Implement TransUNet and loss**

Use pre-normalized Transformer blocks:

```python
class TransformerBlock(nn.Module):
    def forward(self, x):
        x = x + self.attn(self.norm1(x), self.norm1(x), self.norm1(x), need_weights=False)[0]
        return x + self.mlp(self.norm2(x))
```

Build a three-level convolutional encoder and decoder with bilinear upsampling, skip concatenation, and a ViT bottleneck over flattened `H/8 x W/8` tokens. Validate in the model constructor that `embed_dim % transformer_heads == 0`. Pad the input on the right/bottom to a multiple of eight before encoding, then crop logits back to the original `H, W` so non-divisible image sizes remain supported.

```python
class BCEDiceLoss(nn.Module):
    def forward(self, logits, target):
        bce = F.binary_cross_entropy_with_logits(logits, target)
        probs = logits.sigmoid()
        intersection = (probs * target).sum(dim=(1, 2, 3))
        dice = (2 * intersection + 1.0) / (probs.sum((1, 2, 3)) + target.sum((1, 2, 3)) + 1.0)
        return bce + (1.0 - dice.mean())
```

- [ ] **Step 3: Implement metrics with explicit conventions**

Compute Dice and IoU from boolean arrays. Use TP/FP/FN counts for recall and precision, preserving the documented both-empty score of one and one-empty score of zero. For valid foreground pairs, extract surfaces with `scipy.ndimage.binary_erosion`, calculate bidirectional nearest-neighbour physical distances using `scipy.spatial.cKDTree` after multiplying ZYX coordinates by the matching reversed spacing, then calculate HD95 and ASSD.

```python
def binary_volume_metrics(pred, target, spacing_xyz):
    result = _overlap_metrics(pred, target)
    if not pred.any() or not target.any():
        return result | {"hd95": float("nan"), "assd": float("nan")}
    distances = np.concatenate([_surface_distances(pred, target, spacing_xyz), _surface_distances(target, pred, spacing_xyz)])
    return result | {"hd95": float(np.percentile(distances, 95)), "assd": float(distances.mean())}
```
